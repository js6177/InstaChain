Install:
bun
podman (preferred, rootless) or docker
# With Podman, enable the user API socket once:
#   systemctl --user enable --now podman.socket
# Force an engine: export CONTAINER_CLI=podman   # or docker

For native bitcoin key deps on Windows, you may still need:
Microsoft Visual C++ 14.0 or greater (https://visualstudio.microsoft.com/visual-cpp-build-tools/)



# First-time setup (generate keys, start bitcoin-core, wait for sync, import wallet keys):
bun run setup:first-time -- -env=test
# If the wallet already exists and you want to recreate it (keeps synced chain data):
# bun run setup:first-time -- -env=test -overwrite-wallet

# Or fine-tune individual steps:
bun run setup -- -env=test -containered=true -generate-keys -generate-oauth-config
bun run setup -- -env=test -containered=true -import-keys-to-bitcoin-core

make backend-test

To run all tests in containers (Podman/Docker) — unit + integration, no stress:
make test
# or: bun run test:docker

Throughput stress (separate; not part of test:docker):
make stress-test
# make stress-test-health

To debug/run the frontend tests in vscode with the backend in containers:
make backend-test
cp frontend/wallet/apps/web/.env.test.local.example frontend/wallet/apps/web/.env.test.local
cd frontend/wallet/apps/web && bun run test

To run the linter from the root directory:
bun run biome lint --reporter=concise .
